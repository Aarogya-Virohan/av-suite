⚠ Why does users.role have 'patient'?
The users table stores login credentials for staff (admin, therapist, front_desk) and optionally for patients with portal access. A patient who only exists as a clinical record lives in the patients table without any user row. If a patient is given portal login access, a users row is created with role='patient' and linked back via patients.user_id → users.id. So 'patient' in users is for portal-login patients only — not all patients.
